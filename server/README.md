# 랭킹 서버 바꾸는 법 (선생님용)

> 0.035: 시작표에 도장 받기가 들어갔어요. `Code.gs`를 다시 붙여 넣고 **배포 관리 → 새 버전**으로 배포해 주세요.

게임 0.032부터 랭킹이 **단어 조합 닉네임** 방식으로 바뀌었어요. 서버(Google Apps Script)도 이 폴더의 `Code.gs`로 바꿔야 새 랭킹이 돌아가요.

## 바꾸는 순서 (5분)

1. 지금 쓰는 랭킹 스프레드시트를 열고 **확장 프로그램 → Apps Script**로 들어가요.
2. 원래 코드는 혹시 몰라 다른 곳(메모장 등)에 복사해 두세요.
3. 편집기의 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣고 **저장**해요.
4. **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 눌러요.
   - "새 배포"가 아니라 **배포 관리에서 새 버전**으로 해야 주소가 그대로예요. 게임에 적힌 주소도 바꿀 필요가 없어요.
   - 권한을 다시 물으면 허용해요.("확인하지 않은 앱" 화면이면 고급 → 이동)

## 바뀐 뒤 시트

- 새 기록은 **`Ranking` 탭**에 쌓여요(처음 기록이 들어올 때 자동으로 생겨요).
- 예전 기록이 든 **`RankData` 탭은 그대로** 두고 읽기만 해요. 직접 입력 닉네임에는 실명이 섞여 있을 수 있어서 새 랭킹에는 보이지 않아요.
- 학생이 예전에 쓰던 기기에서 새 닉네임을 처음 만들면, 그 기기의 예전 최고 기록(레벨·문제 수·생존 시간·연속 정답)이 한 번 옮겨져요. 앞뒤가 안 맞는 조작 기록은 옮기지 않아요.

## 관리

- 이상한 기록: `Ranking` 탭에서 그 줄을 지우면 사라져요.
- 학생이 기기를 바꿔서 자기 닉네임을 못 쓸 때: 그 줄의 **G칸(닉네임 주인)**을 지워 주세요. 새 기기에서 같은 닉네임을 고르면 그 기기가 주인이 돼요.
- 새 시즌: `Code.gs`의 `SEASON`과 게임 `index.html`의 `RANK_SEASON`을 같이 1 올려요.
- 닉네임 단어를 늘릴 때: `Code.gs`와 `index.html`의 `NICK_WORDS` **맨 뒤에만** 똑같이 덧붙여요(순서를 바꾸거나 지우면 기존 닉네임이 다른 말로 바뀌어요).

## 판 시작표 (0.033부터)

- '작전 개시'를 누르면 서버가 **판 시작표**(서버 시계로 적은 시작 시각 + 서명)를 줘요.
- 게임 오버 때 그 표와 함께 기록을 올리면, 서버가 **도장으로 쌓인 시간보다 긴 생존**과 **한 문제에 5초보다 빠른 풀이**를 잘라 내요.
  게임은 하는 동안 2분마다 시작표에 **도장**을 받아요. 도장 사이가 비면 5분까지만 인정해서, 표만 받아 두고 기다려도 소용없어요.
- 서명 열쇠는 코드에 없고, 처음 쓸 때 **스크립트 속성(TICKET_SECRET)**에 자동으로 만들어져요. 지우면 그때까지 받은 표가 모두 무효가 돼요.
- 시작표가 없는 판(인터넷 없이 시작한 판), 24시간이 지난 표, 다른 기기의 표는 랭킹에 안 올라가요.
- 그래도 막지 못하는 것: 도장까지 자동으로 받는 스크립트나 무적·자동 풀이 스크립트를 켜 두고 **실제로 오래 버티는** 것. 이런 줄은 시트에서 지워 주세요.

## 서버가 막는 것

- 단어 번호가 아닌 닉네임(직접 친 글자)
- 다른 기기가 만든 닉네임으로 기록 올리기
- 시작표가 없거나 위조된 기록, 실제로 흐른 시간을 넘는 기록(잘라 냄)
- 앞뒤가 안 맞는 기록(정답 수보다 높은 레벨, 생존 시간 ÷ 5초보다 많은 정답 등)
- 같은 닉네임으로 2초 안에 다시 올리기, 짧은 시간에 닉네임을 너무 많이 만들기
